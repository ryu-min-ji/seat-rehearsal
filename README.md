# 객석 리허설

> 무대는 리허설을 하는데, 객석은 왜 안 하나요?

공연장 3D 공공데이터로 **무대 구조물(LED 벽 · 스피커 타워) 때문에 가려지는 좌석을 예매 전에 계산**하는 웹 서비스입니다.
2026년도 한국체육산업개발(주) 공공데이터 활용 경진대회 출품작.

## 기능
1. KSPO DOME 고정석 9,366석을 3D로 표시
2. 무대 형태(엔드 · 센터 · 엔드+돌출) 선택, LED 벽 · 스피커 타워 배치 · 크기 조절 · 회전
3. 좌석마다 무대 가시율(%) 실시간 계산 → 잘 보임 / 일부 가림 / 시야제한석 권장 / 판매 비권장 / 무대 뒤(사석)
4. 좌석 클릭 → 그 자리 눈높이에서 본 무대

## 사용한 공공데이터
- 한국체육산업개발주식회사_올림픽공원 공연장 실감형 콘텐츠 (공공데이터포털 15127487, DAE 3D 모델)
  - 3D 모델(약 10만 개 도형)에서 좌석 크기의 물체를 자동 추출해 `data/kspodome_seats.json` 생성

## 실행
정적 웹사이트입니다. 서버 없이 아무 정적 호스팅에서 동작합니다.

```bash
python -m http.server 8123
```
